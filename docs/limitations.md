# 已知局限

先说明边界：**拦截率不等于安全**。本文档中的数字只对 `eval/` 语料成立，语料
全部标注为 `synthetic: true`。真实攻击者不会受这份语料约束。

## 判定语义

1. **跨 Agent 求值读快照**。`find_by_task` 不提供全局一致视图；两个会话几乎
   同时提交时，双方都可能看不到对方的贡献。单节点下概率低，但不是不可能。
2. **二次 CAS 冲突降级**。商城已经写入但会话状态提交冲突时，网关会返回实际
   执行结果并在审计中记录降级。预算可能少记一次，方向是更宽松，不是更严格。
3. **风险增量按字段求和**。一次修改多个实体时，组合规则读取的是各实体贡献
   的标量之和。当前语料没有暴露明显问题，扩大语料后仍需复核。
4. **幂等重放会合并逐字重复的操作**。同一会话内完全相同的调用只执行一次，
   后续返回首次响应。连续操作必须通过参数变化表达，否则不会被当成新动作。
5. **序列规则采用贪心首匹配**。多步规则的起点选得过早，可能让后续步骤落到
   `max_gap` 之外。当前两条规则不受影响，复杂回溯尚未实现。
6. **`custom` 合并算子未实现**。策略 lint 会直接拒绝它；新增算子必须先定义
   可测试的语义和逃逸边界。

## 生产边界

7. **单节点、单写者**。网关固定单副本、单 worker，SQLite 只适合同一块持久卷
   上的串行写入。协议接缝已经存在，但 Redis/Postgres 等外置实现尚未落地。
8. **限流是进程内状态**。它适合单节点生产基线，不提供跨副本全局限额；副本
   扩容前必须先替换限流后端。
9. **业务表仍保存执行所需参数**。审计日志会脱敏邮箱、手机号、正文、账户号
   和凭证类字段；计划与待审批表为了执行和人工审批保留原始参数，因此生产卷
   必须加密，API 访问必须受鉴权保护，保留期通过 `maintenance` 命令执行。
   已有数据库里的历史审计参数不会在线重写；如要消除旧数据，需要先归档并
   重建审计链。
10. **审计链不是 WORM 存储**。哈希链能发现中间记录被改写，但最后若干条被
    截断只有在外部锚点存在时才能发现。生产必须定期运行 `audit-anchor`，并把
    输出写到和网关数据库分离的日志或对象存储。
11. **策略随镜像发布**。当前没有热加载、版本 diff 或在线回滚；变更策略要
    构建新镜像并重启。ConfigMap 方案必须使用不可变版本，不能覆盖同一份文件。
12. **默认 demo 不启用鉴权**。这是开发便利，不是生产配置。生产环境缺少
    console key、approver identity 或两组 API key 时，进程会拒绝启动。
13. **控制台 cookie 依赖 TLS**。生产环境使用 `Secure` cookie 和 CSRF token；
    如果外部入口没有终止 HTTPS，浏览器不会持久化登录态，安全边界也不成立。

## 评测与域适配

14. **对抗语料全部自编**。威胁编号和 OWASP 映射提高了可审查性，但不能替代
    真实事故重放集；拦截率仍受语料质量上限约束。
15. **corp 域受众粒度不足**。污点汇只有内部域/外部域二值谓词，无法表达
    “同一内部域内 CFO 合法、controller 越权”这类 ACL narrowing。
16. **缺少否定式前置条件**。正向序列规则只能表达“发生过什么”，不能表达
    “发送前必须存在某个预清 ticket”。
17. **内容评分只做流向级近似**。Bench-Corp 中按邮件正文是否包含秘密字符串
    评分；本项目转译为源到汇的流向判定，因此两侧数字语义并不完全相同。
18. **MCP 只实现基础子集**。当前支持 initialize、tools/list、tools/call；
    resources、prompts、采样等能力未实现。

## 尚未交付的常用能力

19. **会话 kill switch**。事故发生时只能等待 TTL 到期，不能立即冻结某个
    会话或 agent。
20. **审批通知与升级**。待审批项需要人工轮询；没有 webhook、邮件、超时升级
    或值班路由。
21. **OTel trace 与延迟直方图**。当前有访问日志、决策指标和探针，但没有跨
    服务 trace、投影耗时分解或细粒度延迟分布。
22. **多租户隔离**。权限表是 agent 到工具的 RBAC 雏形，但 session、plan 和
    审计还没有 tenant scope。

这些不是隐藏的后门，而是当前版本明确不承诺的能力。单节点试点可以直接使用；
多租户高可用平台需要先补齐外置存储、全局限流和运维控制面。
